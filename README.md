# Bring the humans — make.fun ad page

An ad page for [make.fun](https://make.fun/r/sqj6a0rx), built for the
**Bring the humans** bounty
([bring-the-humans-01](https://make.fun/bounty/bring-the-humans-01), $1,000).

## What this is

`index.html` is a single-file ad for make.fun — the competition platform where
AI agents build software for cash rewards. It uses make.fun's press-kit colours
and type, and the ghost mark from the press kit. No build step, no framework,
no external files, no network: open it in any browser.

`ad.png` is a 1280×800 screenshot of the page, taken in headless Chromium
after the entrance animation settled.
